# 官方数据库独立更新

“关于 ISAtlas → 检查数据库更新”和“数据包 → 数据库更新”检查 ISAtlas-data 的最新正式 Release。数据库版本独立于 APK；初始状态仅使用内置 Manual，首次下载官方数据库后显示发行版本。

启动并加载数据后自动检查，成功检查间隔至少六小时。检查同时访问 GitHub 官方 API 和现有 GH-Proxy 镜像，选择版本较新的结果。跳过版本只关闭该版本的自动提示，仍保留手动检查和红点入口。

下载由 Android DownloadManager 在后台执行，不阻塞查询；再次检查会打开原任务状态，不创建第二个任务。失败或一分钟没有进展时切换到镜像重试。支持取消下载，进程退出后仍由系统下载，重新打开应用时恢复观察并校验结果。

下载校验完成后自动重建官方数据库并与现有本地包合并，不再要求确认，也不重写本地包文件。如果本地包正在处理或开关正在切换，等待操作完成再自动应用。应用失败时保留旧数据库并提供手动重试，不循环重试。可选官方包保留原启停选择；新增可选包默认关闭，可在数据包页面启用。查询内容一次切换，列表、筛选与详情按新数据校正。

## 完整性与提交

- 只接受官方仓库、规定资产名称、正式版本与 GitHub Release 提供的 SHA-256 digest。
- 下载 ZIP 不超过 32 MiB；核对资产长度和 SHA-256。
- 不解压到文件系统，限制条目数量与展开大小，拒绝重复、越界路径及未列入清单的文件。
- 校验 database.json 的格式版本、数据库版本、文件长度和逐文件 SHA-256。
- 使用应用同源解析器验证各来源包及全部可选组合、CSR、字段、指令、扩展依赖和许可正文。
- 在提交前完成本地包合并；通过 AtomicFile 保存完整数据库，失败继续使用原数据库。重启时若已下载的数据不可读取，回退到内置 Manual 并保留原文件供重新下载修复。

镜像仅接收公开请求，不发送凭据和本地包内容。SHA-256 用于完整性校验，不代替独立的离线签名信任链。此版尚未引入数据库签名、增量下载或预览数据库通道。

数据库更新不会修改 APK 内的资产或应用仓库中的内置基线锁文件；正式构建仍仅携带 Manual。
